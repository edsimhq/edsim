How it works

Built on real standards,
tested in real classrooms.

Every simulation is reviewed against our quality checklist before it goes live.

1

A teacher builds it

Educators create sims using our scaffolded template. No coding required — just classroom expertise.

2

It gets reviewed

Every submission is checked against our build standards: tab nav, auto-save, accessibility, print layout, and standards alignment.

3

You use it tomorrow

Open in any browser. Works on Chromebooks, tablets, and desktops. No accounts, no downloads, no setup.

4

Students save their work

Auto-saves locally as students type. Print to PDF section by section. Works without WiFi once loaded.

Quality checklist

  • ✓ Tab navigation + Prev/Next buttons
  • ✓ Student directions on page one
  • ✓ Auto-save to local storage
  • ✓ Section-select PDF export
  • ✓ Keyboard accessible
  • ✓ Tablet-friendly (768px+)
  • ✓ 4.5:1 contrast ratio
  • ✓ Standards aligned
  • ✓ AI errors handled gracefully
