Checks and Balances

How each branch limits the other two

Welcome

You already know what each branch of government does on its own. This activity is about how each branch limits the other two — the system of checks and balances that keeps any one branch from becoming too powerful.

  • 1
    Legislative, Executive, and Judicial Checks Three tabs, one per branch, covering every check that branch holds over the other two.
    About 10 minutes
  • 2
    Match Sort each check into the branch that holds it.
    About 8–12 minutes
  • 3
    Chain Reaction Read real historical episodes — each one shows a branch taking action, and another branch checking it. Identify which check is happening.
    About 10–15 minutes

By the end of this activity, you'll be able to name the checks each branch holds over the others and recognize them at work in real events.
